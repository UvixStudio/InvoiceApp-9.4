# 📝 דוח סקירה – אפליקציית סריקת חשבוניות (Google Sheets + Apps Script)

## 1. בעיות קריטיות (חייב טיפול מיידי)
### 📌 1.1 סנכרון/העלאת קבצים בזמן סריקה
- **בעיה:** פונקציית הסריקה (`gmailApiAdvanced.gs`) יוצרת קבצים (`DriveApp.createFile`) כבר בזמן קריאת המיילים.  
- **למה קריטי:** זה שובר את ה-flow שדרשת – הסריקה אמורה רק לפתוח גיליון חדש עם רשומות, לא לגעת ב־Drive. נוצרות כפילויות ובלגן.  
- **פתרון:** למחוק כל `createFile` מחוץ ל־`DriveSyncer.gs`. הסריקה כותבת רשומה בלבד, `PDF Link` נשאר ריק עד לייצוא.

---

### 📌 1.2 “קפיצה לשורה 1000”
- **בעיה:** בצד הסריקה נוספו צ’קבוקסים על `A2:A1000` ומולאו FALSE → `getLastRow()` מזהה את 1000 כרצף נתונים.  
- **למה קריטי:** גורם לרשומות חדשות להתחיל משורה 1000.  
- **פתרון:**  
  - להשתמש ב־`firstEmptyRow(sheet)` ולא ב־`getLastRow()+1`.  
  - להוסיף צ’קבוקסים **רק** על מספר השורות שנכתבו בפועל (`sheet.getRange(2,1,count,1).insertCheckboxes()`).

---

### 📌 1.3 שימוש בעמודות קשיחות
- **בעיה:** `Export Folder ID`, `Exclude Emails`, `Approved`, `Keywords` נקראות לפי אות טור (למשל H2).  
- **למה קריטי:** אם תשנה סדר עמודות ב־Settings האפליקציה נשברת.  
- **פתרון:** פונקציות שקוראות לפי **שם כותרת** ולא אות.

---

### 📌 1.4 תפריט “פעולות” לא שלם
- **בעיה:** אין “☑️ סמן הכל”, אין “📦 ייצא הכל”. “📦 ייצא נבחרים” קיים אבל לא מחובר למימוש אמיתי.  
- **למה קריטי:** מונע ממך להשתמש ביכולות בסיסיות.  
- **פתרון:** להוסיף ל־`onOpen()` את כל הפריטים, ולוודא שיש פונקציות תואמות.

---

### 📌 1.5 מנוע ייצוא (DriveSyncer) לא קיים/ריק
- **בעיה:** קובץ `DriveSyncer.gs` אצלך היה ריק.  
- **למה קריטי:** אין יכולת אמיתית לייצא חשבוניות ל־Drive.  
- **פתרון:** להכניס קוד מלא ל־DriveSyncer שמריץ:  
  `Email ID → getAttachments → העלאה ל־Export Folder ID → כתיבת URL`.

---

### 📌 1.6 פורמט תאריכים
- **בעיה:** שימוש לא עקבי ב־`Start Date` / `End Date`, לפעמים `getLastRow` / `Utilities.formatDate` בלי טיים־זון.  
- **למה קריטי:** עלול לפספס או להכפיל רשומות.  
- **פתרון:** תמיד להשתמש ב־`Session.getScriptTimeZone()` + פורמט חד־משמעי `yyyy-MM-dd`.

---

## 2. בעיות רצוי (כדאי לתקן, קשור לאחרות)
### 📌 2.1 בחירת קובץ לייצוא
- **בעיה:** לפעמים האפליקציה לוקחת קובץ אקראי מהמצורפים.  
- **רצוי:** סדר עדיפות:  
  1. `Attachment Name` אם קיים.  
  2. PDF.  
  3. הראשון ברשימה.

---

### 📌 2.2 זרימת Exclude
- **בעיה:** יש פונקציות Exclude אבל אין סיכום ברור (כמה מופעים מכל שולח).  
- **רצוי:** להציג Pop-up עם סיכום לפני מחיקה (כבר הכנתי גרסה כזאת).

---

### 📌 2.3 ניקוי צ’קבוקסים
- **בעיה:** ניקוי נעשה עם `setValue(false)` על טווחים גדולים.  
- **רצוי:** לנקות רק על מספר השורות הפעיל.  

---

### 📌 2.4 דיווח שגיאות
- **בעיה:** לעיתים שגיאות נעלמות או נרשמות חלקית.  
- **רצוי:** לכתוב Note בתא + Toast + לוג ב־Logger.

---

### 📌 2.5 פריטי תפריט שבורים
- **בעיה:** יש פריט “📊 אבחון טבלה” בלי מימוש.  
- **רצוי:** להסיר או לכתוב פונקציה.

---

## 3. בעיות רצוי (לא קריטי ל־MVP)
- דדופליקציה לפי hash ולא רק לפי שם קובץ.  
- סינון MIME יותר חכם (למשל התייחסות ל־.docx / .xlsx).  
- איחוד שמות פונקציות כפולים (`Fixed` / `Advanced`).  
- ממשק משתמש נעים יותר (פופאפ הצלחה/כישלון עקבי).

- 🚫 החרג מסומנים – ✔️  
- 🧹 נקה גיליון / מחק / הוסף למאושרים – ✔️ (לא קריטי כרגע)

# 5. המלצות מיידיות ל־MVP
1. להחליף את **4 הקבצים הקריטיים**: `Helpers.gs`, `gmailApiAdvanced.gs`, `DriveSyncer.gs`, `runActions.gs`.  
2. לוודא שב־Settings הכותרות קיימות ובשורה 2 של **Export Folder ID** יש את ה־ID של התיקייה.  
3. להריץ `scanInvoices()` → יוצר טאב `invoices …` **ללא העלאה**.  
4. מהתפריט “פעולות”:  
   - ☑️ סמן הכל → 📦 ייצא הכל.  
   - או לסמן ידנית → 📦 ייצא נבחרים.  
5. אם יש חשבוניות לא רצויות → 🚫 החרג מסומנים.
